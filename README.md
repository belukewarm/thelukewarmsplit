# lukewarm splitting

Glassy, animated, multi-step app to split Uber Eats / Target order costs fairly.

## Stack
- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- lucide-react

## Dev
```bash
pnpm i    # or npm i / yarn
pnpm dev  # http://localhost:3000
```

## Deploy
- Push to GitHub, import the repo in Vercel, accept defaults. Framework detection: Next.js.
